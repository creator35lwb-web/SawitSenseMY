## Decision 1: Worthwhile or over-engineering?

- **Trigger:** Alton asked whether official-source links that let anyone check the data would add value, or were over-engineering.
- **How SS decided:** the value depends on one fact: can a member of the public actually find our numbers on the linked pages? SS checked before answering:
  - The MPOC page lists "28 Sep 26 4664", the same figure the app shows.
  - MPOB's OER page is public, has month and year pickers, and reads the same `api/oer` we use.
  - MPOB's FFB reference price pages are licensee-only.
- **Verdict:** worthwhile in its small form. It is the product's core promise, the ethical framework already requires sources to be shown, and most of the plumbing already existed (`source_url` in the payload, and `url_launcher` already in the app).
- **Over-engineering boundary (agreed):** none of the following:
  - per-number citations
  - archived copies of source pages
  - data signing
  - a provenance dashboard
  - links to raw APIs
- **Confidence:** high. The check turned "sounds good" into "verified possible".

## Decision 2: Where the share factor and the MPOB page link live

- **Options:**
  - (a) Frontend constants (0.93 and the page URL).
  - (b) Published in the data payload.
- **Chosen: (b).** The factor is part of the method, so it belongs with the data. Any API consumer can then redo the sum too. It also stays correct if the backend changes the factor or the source.
- **Cost accepted:** until the first scrape after the merge, the live `latest.json` has no factor. The sheet leaves the sum out rather than guessing, and SS will trigger a scrape straight after the merge.

## Decision 3: How to resolve K8 (identical regional prices)

- **Options:**
  - (a) Change the regional cards, e.g. show each region's OER or a fair price at the average OER.
  - (b) Explain the calculation in the method sheet.
- **Chosen: (b).** A fair price at the *state average* OER could be mistaken for the smallholder's own price. Their price depends on their own graded OER, which is what the Calculator is for. The sheet explains that the national price per 1% OER is the same everywhere, and that regions differ by OER.

## Decision 4: Make "Learn more" open the link

- **Prior framing:** QQ (Perplexity) wrote that GitHub Pages builds "do not bundle url_launcher", so the banner copied the ADR link to the clipboard.
- **Correction:** the footer has used `url_launcher` on the live site since v0.2.1, so the premise was wrong. Copying a URL is a poor experience on a phone.
- **Change:** all links now open through one `linkOpenerProvider`, which tests can override.
