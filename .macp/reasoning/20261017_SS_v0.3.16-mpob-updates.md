## Decision 1: Where "added on" comes from

- **Rejected: derive it from `prices_YYYY-MM-DD.json`.** Each file is keyed by CPO date and overwritten by every later run with that date. The earliest file holding September (`prices_2026-10-09.json`) was last written on 13 Oct, while the month first arrived on 12 Oct at 13:49 MYT.
- **Chosen:** the scraper records `oer.in_app_since` from now on. It needs no git history in the workflow.
- **The one month that arrived before the field** is seeded from its first data commit, `533bd08`. The seed is a one-line constant, cited in the code.
- **When the date is unknown,** the app leaves it out rather than guessing.
