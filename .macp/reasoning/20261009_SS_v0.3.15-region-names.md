## Decision 1: Where the *Indicative* chip goes

- **Cause:** the title row held the name (`Flexible`, ellipsis) and the chip, while the trailing price column took about a third of the card. At 360 px the name got what was left.
- **Chosen:** the name gets the title line on its own, without an ellipsis, so it wraps if ever too long. The chip moves into a `Wrap` with the source line.
- **Rejected:**
  - a smaller font for the name, which hurts readability for the audience;
  - dropping the chip, because the ethical framework wants every derived price labelled.

## Decision 2: How to test it

- Flutter's test font makes every glyph a full square, so a pixel-exact "fits on one line" test would measure the test font, not Roboto.
- **The test checks the contract instead:**
  - no layout errors at 360 px, in all three languages;
  - no ellipsis or `maxLines` on the name;
  - the chip is on all six cards.
- The visual check is the CI preview at 360 px.

## Decision 3: The profile page

- PR #3 had already brought the profile to v0.3.14.
- Bumping it by hand on each release is churn, so a shields.io dynamic badge now reads the live `version.json`. It is checked: it renders "live: v0.3.14".
