## Decision: start the first official run by hand

- **Why:** the deploy put the new app live at 20:08 UTC, but no scheduled scrape followed. The live data was still the old estimate: correctly labelled indicative by the new app, but not yet MPOB's prices.
- **Why it's safe:**

  - the bot makes the data commit, so the rule that agents never push to `main` holds;
  - the run doubles as the first real check of the new scraper on GitHub's runners.
