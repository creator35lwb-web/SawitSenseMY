- **Trigger:** Alton asked whether auto-deleting head branches and removing merged branches are only repository management.

  - Which PRs every non-`main` branch belongs to (all merged, none open).
  - Whether each tip is already inside `main` (`git merge-base --is-ancestor`, 16 of 16).

- **Also:** the action still waited for an explicit "GO", because it changes a repository setting and deletes branches.

## Decision 3: How to delete

- **Options:**
  - (a) GitHub's branches page in Chrome: 16 separate clicks.
  - (b) One `git push origin --delete` with all 16 names, after re-running the same checks in the same command sequence.
- **Chosen: (b).** It is faster, it leaves a record of each deletion, and it was checked straight afterwards (only `main` left, site 200, PR pages intact).
