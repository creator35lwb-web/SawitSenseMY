## Context

Alton reported two problems: the logo doesn't fit well when the webpage launches, and the price history graph doesn't display fully. Alton also asked what D6 is. SS answered: Track B, MPOB licensee access to the official price. That decision is Alton's.

**How SS diagnosed it.** The Chrome extension wasn't connected, so SS used phone-emulated headless Chrome (puppeteer-core, 412 and 360 px) on the live site. A first attempt with plain `--window-size` gave a misleading cut-off page: Chrome clamps the window to about 500 px wide on Windows.

| Found | Cause |
|---|---|
| Blank white page while ~4 MB of app loads | `index.html` had no launch screen |
| Top-bar logo is a white square with an unreadable picture | The whole 2048 px logo (wordmark included) squeezed into a ~40 px slot |
| 2.7 MB downloaded for a tiny logo; the same file used as favicon, iOS icon, share image and PWA icon | One master file used everywhere; the manifest said 512 px, but the file was 2048 |
| Chart labels collide ("5009" over "5000", "4633" over "4650", "09-25" over "09-28"); latest point on the edge | fl_chart labels the padded min/max as well as the gridlines, and the last date sat next to the previous one |
| The curve dips below real prices between days | Plain curve smoothing |

**#14 (v0.3.5)** fixes all of these. It was **previewed before merge:** CI uploads the web build, SS served it locally and captured phone-sized screenshots. Alton got a before/after image.
