## Context

Alton merged #19. He asked for the pros and cons of staying a web app versus publishing on Google Play, and whether feedback could start with a free Google Form that includes a rating.

**v0.3.9 verified live:**

- **K14 is proven:** the deploy succeeded under the narrower permissions.
- **SonarCloud on `main`:** 0 bugs, 0 vulnerabilities, rated A for reliability and security.
- **The first `:13` scheduled scrape** started 5 h 32 min late (K18).

**Found: K19.** After the app started, the page's `lang` was `en-US` on every phone; choosing from the menu did work.

- **Cause:** found in the compiled bundle. Flutter's `Localizations` widget writes the app's resolved locale to `<html lang>` (`$.aP().a2i(locale)` → the embedding's `setAttribute("lang", …)`). `MaterialApp` declared no locale, so its `en-US` default overwrote the value #19 set at start.

**#20 (v0.3.10):**

- `MaterialApp` gets the reader's locale (en / ms / zh-Hans) and the supported locales, so Flutter sets `lang` itself.
- `builtin_labels.dart` keeps Flutter's built-in Material and Cupertino labels available, in English, for BM and Chinese.
- The JavaScript `setPageLanguage()` from #19 is removed.
- **Verified on the preview build:** phones set to English, Malay and Chinese get `en`, `ms` and `zh-Hans` after start, and the menu switch works. The Chinese and BM screens look unchanged. The D11 phone check still passes.

**Web vs store.** SS's recommendation is web first: the live web app is good enough for now.

- **The web app:** free, works on every phone including iPhone, spreads by link (WhatsApp), and an update reaches everyone minutes after a merge.
- **The store app:** looks more official, is searchable, and shows ratings and usage numbers without tracking. It costs a US$25 account, the 12-tester, 14-day closed test, a second product to maintain, and slower releases.
- **The plan:**
  1. Start the feedback loop now: the Google Form (D14) and Discussions (D16).
  2. Fix freshness (D13).
  3. Revisit the store when feedback shows demand, recruiting the 12 testers through the feedback loop.

**D14 draft.** `docs/feedback-form.md` describes the form:

- 3 questions, including a 1–5 star rating;
- no personal data and no sign-in;
- a trilingual title and questions (BM and 中文 need a native check);
- a hidden "app details" field that the app fills in.

## Decisions Made

| Decision | Rationale | Approved By |
|----------|-----------|-------------|
| Set `MaterialApp.locale` rather than re-apply `lang` after Flutter's first frame | It's how Flutter is meant to learn the app's language, with no race and less code | SS (delegated) |
| Fallback delegates instead of `flutter_localizations` | Flutter's built-in labels stay English as before; no new package, so no lockfile change | SS (delegated) |
| Web first, store later (recommendation) | The feedback loop can start today at no cost, and the store's closed test needs the testers the loop will find | Recommended to Alton (D15) |
