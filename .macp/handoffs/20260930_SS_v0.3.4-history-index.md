## Context

Alton merged #11. SS verified v0.3.3 in production: a manual run of the new code went green end to end, and the live site matches `main`.

**Backlog item 1 (offline cache) was re-scoped, not built.** Two findings:
- It needs a local-storage package. Adding a package means regenerating `pubspec.lock`, which needs Flutter. Flutter isn't installed here, and CI rejects a stale lockfile.
- Caching prices alone only helps once the app has already loaded. True offline use needs a service worker that caches the app shell.

That makes it a scope decision for Alton (D9, recommended: defer). #11 and this PR already cover most of the need.

**Done instead (#12), with no new packages:**

| Change | Why |
|--------|-----|
| `history.json`: 60 days of CPO prices, 4 KB, rewritten every run | The History tab made about 30 sequential requests (about 22 files plus weekend 404s). It now makes one, with a per-day fallback. |
| CI builds the web app on every PR | Web-only compile errors used to surface only at deploy |
| Scraper cron moved from :30 to :13 | GitHub delays scheduled runs most at busy times; runs had been starting 4–8 hours late |
