## Context

Alton asked whether linking to official sources, so that anyone can check the dataset publicly, was worthwhile or over-engineering.

**SS's answer:** worthwhile in its small form. Before recommending it, SS opened each official page as a member of the public:

| Figure | Public page | Verifiable? |
|---|---|---|
| CPO RM 4,664 (28 Sep) | MPOC Daily Palm Oil Prices | Yes. Same figure, same date, no login. |
| Regional OER (Aug) | MPOB Prestasi Sawit OER page | Yes. It has month and year pickers and reads the same API we use. |
| Price per 1% OER | None. This is our own method (ADR-001). | Yes, by arithmetic: CPO × 0.01 × 0.93. |
| MPOB official FFB Reference Price | MPOB sectoral / BEPI | No. Licensee login only. |

Alton approved it ("GO!", decision D8). **#10** carries it out:
- **Backend:** publishes `ffb.indicative_share_factor` and `oer.source_page_url`.
- **App:**
  - The CPO source is a tappable link.
  - "How is this calculated?" shows the sum with today's figures, each region's OER, the MPOB page link, and a plain note about the licensee login. This resolves K8.
  - "Learn more" opens ADR-001.
  - The footer has an "Open data" link.
