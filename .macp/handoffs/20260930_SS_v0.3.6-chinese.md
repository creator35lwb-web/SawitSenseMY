## Context

Alton merged #14 (v0.3.5) and activated SS. SS checked v0.3.5 on the live site; the evidence is in the v0.3.5 handoff. SS then took the top item of the approved backlog: D10, Chinese. It is the third language ethical framework v1.1 asks for, and Alton put it next ("D9 and D10 as next").

**#15 (v0.3.6)** adds Simplified Chinese:

- **The string table.** Every string is in Simplified Chinese, using the terms Malaysian Chinese readers see in the press: 原棕油 (CPO), 鲜果串 (FFB), 出油率 (OER), 收购商 (dealer), and 北马 / 中马 / 南马 / 东海岸 / 沙巴 / 砂拉越 for the regions.
- **A language menu.** It replaces the EN|BM toggle, since three languages don't fit a toggle. The top bar shows EN / BM / 中文, and the menu lists each language in its own script.
- **Dates and ages in Chinese.** Dates read 2026年9月30日 15:09, chart labels read 9月28日, and ages read 5 小时前更新.
- **Five strings that stayed English in BM** ("Close", "Required", "Invalid number", GREEN / AMBER / RED) are now translated in all three languages. The English wording is unchanged.
- **Tests** check that:
  - every language has every key;
  - placeholders survive translation;
  - the Chinese table really is Chinese;
  - the Chinese formats are right;
  - the menu switches the app;
  - the Chinese dashboard and calculator show no English and no raw keys.

**The Chinese is a draft.** SS is not a native reader. A native Chinese reader (Alton, or someone Alton trusts) should read the strings before merge. The PR carries a side-by-side table, and GitHub's "suggest changes" works on `app_zh.dart` lines.

## Decisions Made

| Decision | Rationale | Approved By |
|----------|-----------|-------------|
| Simplified script, Malaysian Chinese terms (原棕油, 鲜果串, 北马 …) | Malaysian Chinese schools teach Simplified; mainland terms (毛棕油, 棕榈油) would read as foreign | SS (delegated; D10 approved by Alton) |
| "Indicative" is 估算 (estimated), not 指示性 | 指示性 is finance jargon; 估算 tells a smallholder plainly that the price is worked out, not official | SS (delegated), for the native reviewer to confirm |
| A menu, not a three-way toggle | "EN \| BM \| 中文" would squeeze the page title at 360 px; each language is named in its own script | SS (delegated) |
| Translate the five leftover English strings in BM too | Same fix, same PR; the English wording is unchanged | SS (delegated) |
| No bundled Chinese font | Flutter web loads only the Noto Sans SC pieces a page needs from Google Fonts. Bundling the font would add megabytes for every user | SS (delegated) |
| Language memory (D11) raised, not built | It changes what every visitor sees first, so it's Alton's call | Raised to Alton |
